تشغيل الافضل بلتعليم

ارفع index.html إلى GitHub Pages. بعدها أكمل إعداد مشروع malik-al-ashtar مرة واحدة من حسابك في Firebase.

١. نشر الملف على GitHub

  1. أنشئ مستودعاً عاماً، ثم ارفع index.html في المستوى الرئيسي واضغط Commit changes.
  2. في Settings → Pages اختر Deploy from a branch وحدّد الفرع الذي رفعت إليه الملف، عادةً main، والمجلد /(root). اضغط Save.
  3. بعد اكتمال النشر، افتح Visit site. شارك رابط الموقع العادي مع الطلاب واحتفظ برابط دليل الإعداد لنفسك.

٢. تفعيل تسجيل الدخول

افتح مشروعك في Firebase. في Authentication → Sign-in method فعّل Email/Password ثم احفظ. أضف نطاق الاستضافة في Authentication → Settings → Authorized domains.

اكتب اسم النطاق فقط، مثل USERNAME.github.io.

فتح إعدادات تسجيل الدخول

٣. قاعدة البيانات وقواعدها

من Firestore Database أنشئ قاعدة Standard بالاسم (default) إذا لم تكن موجودة. اختر وضع الإنتاج. افتح Rules، انسخ القواعد من الزر والصقها ثم اضغط Publish.

إذا كانت هذه القاعدة تخدم تطبيقاً آخر، ادمج قواعد التطبيقين قبل النشر حتى تستمر صلاحيات التطبيق الآخر.

٤. إنشاء فهارس التطبيق

لإنشائها دفعة واحدة، افتح Google Cloud Shell بحساب المشروع، انسخ الأوامر والصقها ثم اضغط Enter. الأوامر موجهة إلى مشروع malik-al-ashtar وتضيف الفهارس المركّبة. رسالة ALREADY_EXISTS تعني أن الفهرس موجود.

فتح Cloud Shell متابعة حالة الفهارس
عرض الأوامر
إنشاء الفهارس يدوياً من Firebase Console

في Firestore Database → Indexes → Composite → Add index اختر Collection لنطاق الاستعلام. أدخل حقول كل سطر بالترتيب الظاهر ثم اختر Create.

من Indexes → Single field يمكنك تعطيل فهرسة الحقول الآتية على مستوى المجموعة. لا يستخدمها التطبيق للبحث.

    انتظر ظهور الحالة Enabled أو Ready قبل تجربة القنوات والتصنيف.

    ٥. تجربة أول شعبة

    ادخل كأستاذ وأنشئ شعبة. شارك كودها مع طالب، وانشر سؤالاً واحداً. بعد تسليم الطالب إجابته، تقدر تشوف أثرها في تصنيف الطالب والأستاذ والشعبة.
